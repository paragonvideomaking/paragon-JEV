# ТЗ перед стартом

Локальное демо: вставляете техническое задание — получаете пять статусов по
чек-листу, ясность результата, проверку приёмки и уточняющие вопросы. Оценку
делает реальный API TypeSafe (модель `jev-latest`).

## Требования

- Python 3
- Браузер
- API-ключ TypeSafe

## Запуск

```
python3 app.py
```

Сервер слушает только `127.0.0.1`. Порт по умолчанию 8000; если занят, берётся
следующий свободный. Фактический адрес печатается в консоли, например:

```
http://127.0.0.1:8001
```

Откройте этот адрес в браузере, введите API-ключ на экране подключения, вставьте
ТЗ и нажмите «Проверить ТЗ».

Остановить: `Ctrl+C` (или `pkill -f "app.py"`). После остановки ключ нужно
ввести заново.

## Тесты

```
python3 -m unittest tests.test_rules
```

## Заметки

- Ключ хранится только в памяти процесса, в файлы и ответы не попадает.
- Учебные пороги (confidence и Noul) заданы в `rules.py`.
- Реальные запросы пишутся в `runs/` (без секретов).
- `fixtures.json` — тестовые примеры ввода, не оценка качества модели.
